# Reports

`reports/` contains output generated by Browser Kitty Apps registry checks.

## Repository inventory

Run:

```powershell
./scripts/check-repositories.ps1
```

The command writes `reports/repository-inventory.json` by default. The generated file records the current GitHub state for every entry in `apps.json`, including:

- repository existence
- public/private visibility
- archived state
- default branch
- latest GitHub Release when one exists

The generated inventory is intentionally not committed. GitHub Actions uploads it as a workflow artifact instead. The registry itself remains the source of managed metadata.

## Authentication

The inventory works anonymously for public repositories. If a larger registry needs a higher API rate limit, set `BROWSER_KITTY_GITHUB_TOKEN` to a dedicated token that can read the target repositories. The built-in Actions `GITHUB_TOKEN` is intentionally not used for cross-repository inventory.
